### PROMPT: Write a Python function that returns the n-th Fibonacci number.
Here is a Python function that returns the n-th Fibonacci number using recursion:

```python
def fibonacci(n):
    if n <= 0:
        return "Input should be a positive integer."
    elif n == 1:
        return 0
    elif n == 2:
        return 1
    else:
        return fibonacci(n-1) + fibonacci(n-2)
```

### PROMPT: Explain in two sentences why the sky is blue.
The sky appears blue due to a process called Rayleigh scattering, where shorter-wavelength light, such as blue and violet light, is scattered more than longer-wavelength light, like red, orange, and yellow, by the Earth's atmosphere. This scattering is more pronounced in blue and violet light, causing the sky to appear blue to our eyes. [end of text]
